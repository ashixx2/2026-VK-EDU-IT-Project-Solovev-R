# Recipe from Fridge

## Описание проекта

**Recipe from Fridge** — это B2C-приложение, которое помогает пользователю подобрать рецепты по продуктам, которые уже есть дома.

Пользователь добавляет продукты из холодильника, а приложение предлагает подходящие рецепты, показывает недостающие ингредиенты и помогает меньше выбрасывать еду.

## Бизнес-модель

**B2C — Business-to-Consumer**

Продукт предназначен для обычных пользователей:

- студентов;
- людей, которые живут одни;
- молодых семей;
- занятых людей, которые хотят быстро готовить дома и экономить на еде.

## Основная идея

Многие люди сталкиваются с ситуацией, когда дома есть продукты, но непонятно, что из них приготовить. Из-за этого продукты портятся, деньги тратятся впустую, а пользователь снова покупает лишнее или заказывает доставку.

**Recipe from Fridge** решает эту проблему: пользователь вводит продукты из холодильника, а приложение предлагает блюда, которые можно приготовить из уже имеющихся ингредиентов.

## Цель проекта

Создать MVP мобильного приложения, которое проверяет главную гипотезу:

> Пользователю полезно приложение, которое подбирает рецепты по продуктам, уже имеющимся дома.

## [Практическое задание №3 — DDD, BDD, Wireframes, API-First](Exercise3/README.md)
