# FocusPet

## Elevator Pitch

Многие студенты хотят учиться регулярно, но часто отвлекаются на телефон, соцсети и откладывают задания до последнего момента.

FocusPet — это мобильное B2C-приложение, которое помогает студентам бороться с прокрастинацией через игровой таймер фокусировки и виртуального питомца.

В отличие от обычных таймеров, FocusPet превращает учебу в игру: чем дольше студент занимается без отвлечений, тем быстрее развивается его питомец и открываются новые награды.

В результате студенту проще начать учиться, удерживать концентрацию и видеть свой прогресс.

Сейчас мы хотим протестировать MVP среди студентов и проверить, помогает ли игровой формат чаще садиться за учебу.

## Lean Canvas

| Блок | Содержание |
|---|---|
| **1. Проблема** | Студенты часто прокрастинируют, отвлекаются на телефон и откладывают учебные задачи до последнего момента. Обычные таймеры и планировщики кажутся скучными и не создают мотивации. |
| **2. Сегменты потребителей** | Студенты колледжей и университетов, школьники старших классов, люди, которым сложно концентрироваться на учебе. Ранние пользователи — студенты во время сессии и дедлайнов. |
| **3. Уникальная ценность** | FocusPet помогает учиться без отвлечений через игровую механику: пользователь фокусируется, а его виртуальный питомец развивается. |
| **4. Решение** | Таймер фокусировки, виртуальный питомец, награды, уровни, статистика учебного времени, напоминания и предупреждения при выходе из приложения. |
| **5. Каналы** | App Store, Google Play, студенческие Telegram/VK-сообщества, TikTok, VK Клипы, YouTube Shorts, учебные блогеры, сарафанное радио. |
| **6. Потоки прибыли** | Бесплатная версия, платная подписка, покупка дополнительных питомцев, косметические предметы, премиум-темы, версия Pro без рекламы. |
| **7. Структура издержек** | Разработка мобильного приложения, дизайн питомцев, серверы, поддержка пользователей, маркетинг, публикация в магазинах приложений, тестирование. |
| **8. Ключевые метрики** | Количество установок, активные пользователи в день, число фокус-сессий, средняя длительность сессии, удержание пользователей, количество подписок, выручка. |
| **9. Скрытое преимущество** | Узкий фокус на студентах, эмоциональная привязка к питомцу, простая игровая механика, возможность быстро тестировать новых питомцев и награды. |
